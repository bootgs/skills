# corpus/

Scratch space for pages a skill's `scripts/` fetched — quota tables, review
checklists, registry responses.

**Nothing in here is version-controlled.** `.gitignore` keeps this README and
drops everything else, because the contents belong to whoever published them,
not to this repository, and a committed copy is a redistribution rather than a
cache. `tests/repo/coverage.test.ts` fails if anything else here is tracked.

A stored copy is also not an answer. When a script serves one, it says so —
see `stored_copy_result` in `template/scripts/fetch_policy.py`, which stamps
every cached body with the date it was retrieved so a figure from here is never
mistaken for a live one.
